# Use grandma3-specs (consume)

Follow [`.agents/rules/consume.md`](../../rules/consume.md) and [`AGENTS.md`](../../../AGENTS.md).

## Quick path

1. `specs/versions.md` → Target  
2. Unfamiliar area → `specs/concepts/_index.md`  
3. Depth → linked Topic Spec  
4. Tokens → `specs/keywords/_index.md` → one file  
5. Multi-station questions → `specs/multi-station.md`  
6. Compose strings → `specs/command-line.md`  

Do not invent keywords or session behavior. To **change** Specs, switch to [contribute-specs](../contribute-specs/SKILL.md).
