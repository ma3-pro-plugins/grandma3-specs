# Groups

Groups store a fixture selection (order + grid position). Fast way to select fixtures; can also act as **group masters** (four types — manual Group Master topic).

Groups live in the Groups pool. Cues/presets do **not** store a group reference — only fixture values. **Recipes can reference groups.**

## Syntax

```
Group 3
Store Group 5
Delete Group 5
```

Confirm Store/Delete defaults and options on Keyword Specs: [`Group`](../keywords/Group.md), [`Store`](../keywords/Store.md), [`Delete`](../keywords/Delete.md).
