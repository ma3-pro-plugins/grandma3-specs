# Agenda

The agenda **schedules objects** (sequences, macros, plugins) or commands to run from the calendar (including repeating every minute / day / week / month / year).

Keyword: [`Agenda`](../keywords/Agenda.md).

**Topic Spec (depth — view modes, entry properties, Official Assign/Label/Set examples):** [`../agenda.md`](../agenda.md).

Assigns sequence 1 to agenda event 1:

```
Assign Sequence 1 At Agenda 1
```
