# Quickeys

Quickeys are **soft versions of hardkeys and functions**. They live in the Quickeys pool (under Data Pools) and can be assigned to Xkeys, layouts, or executors, or used from the pool.

Keyword: [`Quickey`](../keywords/Quickey.md).

**Topic Spec (depth — Edit Quickey, pool LEDs, editor Code list, pool settings):** [`../quickeys.md`](../quickeys.md).

Opens the editor for Quickey 1:

```
Edit Quickey 1
```

Part of Data Pools: [`datapools.md`](datapools.md).
