# Single User and Multi User Systems

Sessions may run single-user or multi-user.

| Mode | Manual summary |
| --- | --- |
| **Single user / Full Tracking Backup** | Same User on stations — shared views and **shared programmer** |
| **Multi user** | Different Users (often profiles) — shared show/sequences; **programmers not shared**; output is |
| **Mixed** | Multi-user operators each with tracking backup stations |

Rights span admin down to view-only. Preview programmer caveat in session: see [`programmer.md`](programmer.md).
