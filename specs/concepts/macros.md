# Macros

Macros are **commands stored in a pool object**. A line can be simple or a long CLI string. The Macro pool is shared among users in the show file (macro 10 is the same object for every user).

```
Macro 1
```

```
Store Macro 2
```

Macro lines are ordinary CLI strings (bare commands). Where a macro runs in a session: [`../multi-station.md`](../multi-station.md).
