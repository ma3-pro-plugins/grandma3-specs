# Executors

Executors are playback assignments (physical/virtual). Configure, assign objects, inspect running playbacks, special executors.

## Syntax pointers

Assign / On / Off / Go family — confirm each Keyword Spec before use. Sequence playback often goes through executors; bare sequence Go also works (see [`cues-sequences.md`](cues-sequences.md)).
