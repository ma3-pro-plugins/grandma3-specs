## Official

To enter the GoboImage keyword in the command line, use one of the options: 

  * Type **GoboImage**
  * Type the shortcut **Gob**

###  Description 

The keyword GoboImage is an object keyword. It is used to manage images of gobos using the command line. 

###  Syntax 

[Function] GoboImage ["GoboImage_Name" or GoboImage_Number]

###  Examples   
  

  * To edit gobo image 1 in the gobo pool, type: 

```
Edit GoboImage 1
```
---|---  
  
  * To list all gobo images in the gobo pool, type: 

```
List GoboImage
```
---|---
