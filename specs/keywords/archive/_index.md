# Archived keywords

Keywords **gone from Target**, or **deprecated ≥ 24 months** (see [`CONTEXT.md`](../../../CONTEXT.md) Keyword lifecycle).

Same file format as live Keyword Specs (Official + Extra, `introduced` / `deprecated`). Option keywords: [`options/`](options/).

Agents: do not emit these in new macros or OSC for Target. Use this folder only to decode old shows, or check a `ma-<version>` git tag for the Spec tree as of that Target.
