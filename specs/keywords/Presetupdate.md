## Official

To enter the PresetUpdate keyword in the command line, use one of these options:

  * Type **PresetUpdate**
  * Type the shortcut **Presetu**

### Description

The PresetUpdate keyword is an object keyword that contains all presets that can be currently updated.

To show the preset list, use the [List keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_list.html).

### Syntax

**[Function]** PresetUpdate (["PresetUpdate_Name" or PresetUpdate_Number])

### Examples  
  

  * To list all the presets that can be updated in the command line feedback, type:

```
List PresetUpdate
```
---|---  
  
The same list is displayed in the [Update Menu](https://help.malighting.com/grandMA3/2.5/HTML/cue_update.html).

  * To update the second preset that is part of the PresetUpdate List , type:

```
Update PresetUpdate 2
```
