## Official

To enter the Learn keyword in the command line, use one of the options:

  * Type **Learn**
  * Type the shortcut**Lear**

###  Description 

The Learn keyword is a playback keyword that is used to determine the starting point and the speed of a phaser at the same time. It is a combination of [LearnSpeed](https://help.malighting.com/grandMA3/2.5/HTML/keyword_learnspeed.html) and [ReSync](https://help.malighting.com/grandMA3/2.5/HTML/keyword_resync.html) keywords. 

For more information on the function Learn and phasers see [Phasers](https://help.malighting.com/grandMA3/2.5/HTML/phaser.html). 

###  Syntax 

**Learn([Object] ["Object_Name" or Object_Number])**

###  Example  

Requirement for the first example below: Select a sequence

  * To apply Learn to the selected sequence, type:

```
Learn
```
---|---  
  
  

  * To adjust the effects onto the phase and speed of the phaser in sequence 15, type:

```
Learn Sequence 15
```
---|---  
  
For more information on the key and its location see [Learn | Rate1 key](https://help.malighting.com/grandMA3/2.5/HTML/key_learn.html).
