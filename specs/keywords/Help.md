To directly open the Help using the command line, use one of the options:

  * Press `Help`
  * Type **Help**
  * Type the shortcut **H**

|  **Hint:**  
---|---  
For more information on how to open the help see [Open the Help in the Console](https://help.malighting.com/grandMA3/2.5/HTML/atm_open_help_console.html).  
  
### Description

Help is a function keyword which is used to open the Help pop-up for you to search for topics or to use the context sensitive help.

### Syntax

Help ["Search_Term"]

### Example  

  * To open the help topic of the Macro keyword, type:

```
Help Macro
```
