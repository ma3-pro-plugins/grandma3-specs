## Official

To enter the Align keyword in the command line, use one of the options:

  * Press `Align`
  * Type **Align**
  * Type the shortcut **Al**

### Description

The Align keyword is a function keyword which is used to toggle through the align modes of the attribute encoders. 

To toggle through the modes, repeatedly press `Align`. 

Align Mode | Index Number  
---|---  
Off | 0  
/ | 1  
< | 2  
> | 3  
>< | 4  
<> | 5  
  
For more information on the align modes, see [Operate Fixtures - Align](https://help.malighting.com/grandMA3/2.5/HTML/operate_align.html).

### Syntax

Align ["Align_Mode" or Align_Index_Number]

### Examples  
  

  * To set the encoders to the first align mode, type:

```
Align "<"
```
---|---  
  

  * To disable the align mode altogether, type:

```
Align 0
```
---|---  
  

For information on the key and its location see [Align key](https://help.malighting.com/grandMA3/2.5/HTML/key_align.html).
