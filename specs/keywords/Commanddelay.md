## Official

To enter the CommandDelay keyword in the command line, use one of the options:

  * Type **CommandDelay**
  * Type the shortcut **Com**

### Description

The CommandDelay sets the delay time when executing commands in a cue.

### Syntax

CommandDelay [CommandDelay_Value]

([Function]) (Sequence ["Sequence_Name" or Sequence_Number]) Cue ["Cue_Name" or Cue_Number] CommandDelay [CommandDelay_Value]

### Example  
  

  * To create cue 3 and set the cue's command delay to 4 seconds, type:

```
​Store Cue 3 CommandDelay 4
```
