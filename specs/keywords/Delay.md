## Official

To enter the Delay keyword in the command line, use one of the options:

  * Press `Time` `Time` (If the Time Key Target is set to Fixture. For more information see [User Settings](https://help.malighting.com/grandMA3/2.5/HTML/users_and_profiles_configuration.html) and [Time Key](https://help.malighting.com/grandMA3/2.5/HTML/key_time.html).)
  * Press `MA` `Time` `Time` `Time`
  * Type **Delay**
  * Type the shortcut **Dela**

### Description

Delay sets the delay time of an object.

For more information on the delay times for cues see [CueDelay Keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_cuedelay.html).

### Syntax

Delay [Delay_Time]

### Example  
  

  * To set an individual delay time of 4 seconds in the current selection, type:

```
Delay 4
```
