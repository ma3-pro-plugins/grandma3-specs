## Official

To enter the Cut keyword in the command line, use one of the options:

  * Press `MA` \+ `Copy`
  * Type **Cut**

### Description

The Cut keyword**** is a function keyword used to specify the source objects for a two-step action.

### Syntax

Cut [Object] ["Object_Name" or Object_Number]

The object is temporarily stored for later use as source object for the following Paste command.

For more information on Cut & Paste see the [Paste Keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_paste.html).

### Example  
  

  * To prepare the color preset 1 to be moved using the Paste keyword, type: 

```
Cut Preset 4.1
```
