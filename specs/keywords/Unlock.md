## Official

To enter the Unlock keyword in the command line, use one of the options:

  * Type **Unlock**
  * Type the shortcut**UL** or **Unl**

### Description 

The Unlock keyword is a function keyword which is used to unlock objects that were previously locked.

For more information on locks and their types see [Lock and Unlock Pool Objects](https://help.malighting.com/grandMA3/2.5/HTML/wvm_pool_lock_unlock.html).

### Syntax

Unlock [Object] ["Object_Name" or Object_Number]

### Option Keywords

The Unlock keyword uses the following option keywords:

[/Recursive](https://help.malighting.com/grandMA3/2.5/HTML/ok_recursive.html)

### Examples  
  

  * To unlock cue 3 to edit the cue, type:

```
Unlock Cue 3
```
---|---  
  
  * To unlock world 3 to edit the world, type:

```
Unlock World 3
```
---|---  
  
  * To unlock the macro line 2 of the macro 1, type:

```
Unlock Macro 1.2
```
---|---
