## Official

To enter the CueUpdate keyword in the command line, use one of the options:

  * Type **CueUpdate**
  * Type the shortcut **Cueu**

### Description

CueUpdate keyword is an object keyword which addresses all cues that can be updated.

### Syntax

**[Function]** CueUpdate [CueUpdate_Number]

### Examples  
  

  * To list all the cues that can be updated in the command line feedback, type:

```
List CueUpdate
```
---|---  
  

It is the same list shown in the [Update menu](https://help.malighting.com/grandMA3/2.5/HTML/cue_update.html).

|  **Important:**  
---|---  
The number relates to the first element in the list. It does not represent the cue number.   
  
  
  * To update the first cue in the list, type:

```
Update CueUpdate 1
```
---|---
