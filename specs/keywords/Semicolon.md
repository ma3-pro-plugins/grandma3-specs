## Official

To enter the : (Semicolon) in the command line, type` ;`. 

### Description

The semicolon separates multiple commands.

### Syntax

[Command]; [Command]

### Example  
  

  * To turn off sequence 5 and delete group 3, type:

```
Off Sequence 5; Delete Group 3
```
