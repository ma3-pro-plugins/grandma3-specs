## Official

To enter the . [Dot] in the command line, press ` . `

### Description

The dot is a separator which is used in fractional digits and hierarchic IDs of objects.

|  **Important:**  
---|---  
Make sure to use the dot without spaces.  
  
  
### Syntax

[Command] [Value].[Value_Fraction]

[Command] [Parent_Number].[Child_Number]

### Examples  
  

  * To call the second color preset for fixture 31.2, type:

```
Fixture 31.2 At Preset 4.2
```
---|---  
  
  * To set the pan attribute to 50.5, type:

```
Attribute "Pan" At 50.5
```
---|---  
  

For information on the key and its location see [. [Dot] key](https://help.malighting.com/grandMA3/2.5/HTML/key_dot.html).
