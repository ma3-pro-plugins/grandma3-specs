## Official

To enter the Appearance keyword in the command line, use one of the options:

  * Press `MA` \+ `X4` \+ `X4`
  * Type **Appearance**
  * Type the shortcut **Ap**

### Description

The Appearance keyword is used to assign an appearance to an object. 

For more information see [Appearance](https://help.malighting.com/grandMA3/2.5/HTML/appear.html). 

### Syntax

**Assign Appearance ["Appearance_Name" or Appearance_Number] At [Object] ["Object_Name" or Object_Number]**

### Examples  
  

  * To assign appearance 3 to group 1, type:

```
Assign Appearance 3 At Group 1
```
---|---  
  

  * To assign appearance "Sunset" to group 2, type:

```
Assign Appearance "Sunset" At Group 2
```
---|---
