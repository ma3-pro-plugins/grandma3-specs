## Official

To enter the Preview keyword in the command line, use one of the options: 

  * Press `Preview`
  * Type **Preview**
  * Type the shortcut **Previe**

###  Description 

The Preview keyword is used to toggle the preview mode. For more information on preview see [What is the Programmer](https://help.malighting.com/grandMA3/2.5/HTML/operate_programmer.html). 

###  Syntax 

Preview (On/Off)

###  Example   
  

  * To toggle the preview mode, type: 

```
Preview
```
---|---  
  
The title bar and the frame around the windows that display the preview mode turn red. 

For information on the key and its lcoation see [Prvw [Preview] key](https://help.malighting.com/grandMA3/2.5/HTML/key_prvw.html).
