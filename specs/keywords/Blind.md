## Official

To enter the Blind keyword in the command line, use one of the options:

  * Press `Blind`
  * Type **Blind**
  * Type the shortcut **B**

### Description

The Blind keyword is used to suppress the output of the live programmer. It is possible to program without putting the content live. Disabling Blind activates the programmer and the changes made during the mode.

Use the [DMX sheet](https://help.malighting.com/grandMA3/2.5/HTML/patch_dmx_sheet.html) to see that the output is set to 0.

| **Hint:** |
| --- |
| Blind is a toggle function which means that entering Blind without using a helping keyword enables or disables it. |

### Syntax

Blind (On or Off)

### Example

  * To enable Blind and to disable the output of the programmer in return, type:

| User name[Fixture]>Blind |
| --- |

For information on the key and its location see [Blind key](https://help.malighting.com/grandMA3/2.5/HTML/key_blind.html).
