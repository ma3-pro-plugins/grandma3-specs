## Official

To enter the Page keyword in the command line, use one of the options:

  * Press `MA` \+ `X15 | Page`
  * Type **Page**
  * Type the shortcut **P**

|  **Important:**  
---|---  
Before calling a page, create a page in the page pool first.  
  
  
### Description

The Page keyword is an object keyword which is used to access pages.

### Syntax

([Function]) Page ["Page_Name" or Page_Number] ([/Option] ["Option_Value"])

### Option Keywords

The Page keyword uses the following option keywords:

  * [/Tab](https://help.malighting.com/grandMA3/2.5/HTML/ok_tab.html)

### Examples  
  

  * To change to page 2, type:

```
Page 2
```
---|---  
  
  * To label page 2 "Ray", type:

```
Label Page 2 "Ray"
```
---|---  
  
  * To call the page with the name "Ray", type:

```
Page "Ray"
```
---|---  
  
  * To change to the next page, type:

```
Next Page
```
---|---  
  
For information on the Page- and Page+ keys and their location see [Page- key](https://help.malighting.com/grandMA3/2.5/HTML/key_page_m.html), and [Page+ key](https://help.malighting.com/grandMA3/2.5/HTML/key_page_p.html), or [X15 | Page key](https://help.malighting.com/grandMA3/2.5/HTML/key_x15.html).
