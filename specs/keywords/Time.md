## Official

To enter the Time keyword in the command line, type **Time.**

### Description

The Time keyword is used to toggle the time overwrite function on sequences. 

For more information see [Cue Timing topic](https://help.malighting.com/grandMA3/2.5/HTML/cue_timing.html).

For more information on how to set time see [FaderTime keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_fadertime.html).

For information on how to assign executors see [Assign Objects to an Executor](https://help.malighting.com/grandMA3/2.5/HTML/executor_assign.html). 

### Syntax

Time (On/Off) [Object] ["Object_Name" or Object_Number]

|  **Hint:**  
---|---  
If the sequence ID is not defined, the sequence that is selected will be affected.  
  
  
### Examples  
  

  * To toggle the time function on the selected sequence, type:

```
Time
```
---|---  
  
  * To enable the time overwrite in sequence 4, type:

```
Time On Sequence 4
```
---|---  
  
For information on the key and its loction see [Time key](https://help.malighting.com/grandMA3/2.5/HTML/key_time.html).
