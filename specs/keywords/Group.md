## Official

To enter the Group keyword in the command line, use one of the options:

  * Press `Group`
  * Type **Group**
  * Type the shortcut **G**

### Description

The Group keyword is an object type that contains a certain selection of fixtures in a specific order along with xyz-coordinates used in the [Selection window](https://help.malighting.com/grandMA3/2.5/HTML/operate_selection.html).

The default function of the Group keyword is SelFix. This means that calling groups without specifying any function selects the fixtures within the group.

For more information see the [SelFix keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_selectfixtures.html).

### Syntax

([Function]) Group ["Group_Name" or Group_Number]

### Option Keywords

The Group keyword uses the following option keywords:

  * [/GridMergeMode](https://help.malighting.com/grandMA3/2.5/HTML/ok_gridmergemode.html)
  * [/Merge](https://help.malighting.com/grandMA3/2.5/HTML/ok_merge.html)
  * [/Overwrite](https://help.malighting.com/grandMA3/2.5/HTML/ok_overwrite.html)
  * [/Remove](https://help.malighting.com/grandMA3/2.5/HTML/ok_remove.html)

### Examples

  * To select the fixtures stored in group 3, type:

| User name[Fixture]>Group 3 |
| --- |

  * To list all stored groups of the group pool in the command line history, type:

| User name[Fixture]>List Group |
| --- |

For information on the key and its location see [Group key](https://help.malighting.com/grandMA3/2.5/HTML/key_group.html).
