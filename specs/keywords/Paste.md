## Official

To enter the Paste keyword in the command line, use one of the options:

  * Press `Copy` `Copy`
  * Type **Paste**
  * Type the shortcut **Pas**

### Description

The Paste keyword pastes or moves previously cut or copied objects. 

For more information see the [Cut keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_cut.html) and the [Copy keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_copy.html). 

### Syntax

Paste Object ["Object_Name" or Object_Number] (/Option)

### Option Keywords

The Paste keyword uses the following option keywords:

  * [/Date](https://help.malighting.com/grandMA3/2.5/HTML/ok_date.html)

### Examples  
  

  * To cut and then paste group 1 to group 5, type:

```
Cut Group 1
```
---|---  
```
Paste Group 5
```
---|---  
  
  * To copy and then paste cue 5 to cue 15, type:

```
Copy Cue 5
```
---|---  
```
Paste Cue 15
```
---|---  
  
  

  * To copy and then paste macro 10 to macro 15, type:

```
Copy Macro 10
```
---|---  
```
Paste Macro 15
```
---|---  
  
|  **Important:**  
---|---  
The pasted object will have all the edits that were made to the source object after copying it to clipboard and before pasting it as a new target object.
