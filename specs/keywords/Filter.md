## Official

To enter the Filter keyword in the command line, use one of the options:

  * Press `Group` `Group` `Group`
  * Type **Filter**
  * Type the shortcut **Fil**

### Description

The Filter keyword is used to call a filter. It represents an attribute and a layer filter.

For more information see [Worlds and Filters](https://help.malighting.com/grandMA3/2.5/HTML/worldfilter.html). 

### Syntax

[Function] Filter ["Filter_Name" or Filter_Number] (/Option)

### Option Keywords

The Filter keyword uses the following option keywords:

  * [/Overwrite](https://help.malighting.com/grandMA3/2.5/HTML/ok_overwrite.html)

### Example  
  

  * To call filter 4, type:

```
Filter 4
```
