## Official

To enter the SpecialExecutor keyword in the command line, use one of the options:

  * Press `MA` \+ `X16 | Exec` \+ `X16 | Exec`
  * Type **SpecialExecutor**
  * Type the shortcut **SE or Sp**

### Description

The SpecialExecutor keyword addresses special executors. 

For more information on the configuration see [Special Executors](https://help.malighting.com/grandMA3/2.5/HTML/executor_special.html) and [Executor Configurations](https://help.malighting.com/grandMA3/2.5/HTML/executor_configurations.html).

### Syntax

[Function] SpecialExecutor ["SpecialExecutor_Name" or SpecialExecutor_Number]

### Examples  
  

  * To open the menu **Special Executor Configuration** , type:

```
Assign SpecialExecutor 7
```
---|---  
  
  * To assign the functionality of grand master to SpecialExecutor 2, type:

```
Assign Master 2.1 At SpecialExecutor 2
```
---|---
