## Official

To enter the **NonDim** keyword in the command line, use one of the options: 

  * Press `Channel` until NonDim appears in the command line 
  * Type **F** \+ **4**
  * Type **NonDim**
  * Type the shortcut **Non**

|  **Hint:**  
---|---  
To use the NonDim keyword, make sure you assign the NonDim ID type and a custom ID to a fixture first.   
  
  
###  Description 

The NonDim keyword is an object keyword which is used to call fixtures of the ID type NonDim in the programmer. 

The name of this keyword can change because it is a custom ID type. For more information see the [Custom ID Type Topic](https://help.malighting.com/grandMA3/2.5/HTML/patch_what_are_fixtures.html). 

###  Syntax 

NonDim ["NonDim_Name" or NonDim_Number]

###  Example   
  

  * To select the fixture that uses the NonDim ID 1, type: 

```
NonDim 1
```
