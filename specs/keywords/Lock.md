## Official

To enter the Lock keyword in the command line, use one of the options:

  * Type **Lock**
  * Type the shortcut **Loc**

### Description

The Lock keyword is a function keyword that locks objects. 

Objects that are locked are indicated by a padlock. 

For more information on locks and their types see [Lock and Unlock Pool Objects](https://help.malighting.com/grandMA3/2.5/HTML/wvm_pool_lock_unlock.html).

### Syntax

Lock [Object] ["Object_Name" or Object_Number]

### Option Keywords

The Lock keyword uses the following option keywords:

[/Recursive](https://help.malighting.com/grandMA3/2.5/HTML/ok_recursive.html)

### Examples  
  

  * To lock macro 1, type:

```
Lock Macro 1
```
---|---  
  
To unlock objects see the [Unlock Keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_unlock.html).

  * To lock the second color preset 2, type:

```
Lock Preset 4.2
```
---|---  
  
  * To lock sequence 3, type:

```
Lock Sequence 3
```
---|---
