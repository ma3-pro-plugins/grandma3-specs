## Official

To enter the Update keyword in the command line, use one of the options:

  * Press `Update`
  * Type **Update**
  * Type the shortcut **U**

### Description

The Update keyword is a function keyword which is used to update values in their source objects.

### Syntax

Update [Object]["Object_Name" or Object_Number or Next/Previous]

### Option Keywords

The Update Keyword uses the following option keywords:

  * [/AddNewContent](https://help.malighting.com/grandMA3/2.5/HTML/ok_addnewcontent.html)
  * [/ForceGlobal](https://help.malighting.com/grandMA3/2.5/HTML/ok_forceglobal.html)
  * [/Global](https://help.malighting.com/grandMA3/2.5/HTML/ok_global.html)
  * [/InputFilter](https://help.malighting.com/grandMA3/2.5/HTML/ok_inputfilter.html)
  * [/OriginalContentOnly](https://help.malighting.com/grandMA3/2.5/HTML/ok_originalcontentonly.html)
  * [/Selective](https://help.malighting.com/grandMA3/2.5/HTML/ok_selective.html)
  * [/Universal](https://help.malighting.com/grandMA3/2.5/HTML/ok_universal.html)

### Examples  
  

  * To update Preset 4.1, type:

```
Update Preset 4.1
```
---|---  
  
  

|  **Important:**  
---|---  
The following examples can only be applied to already existing cues!  
  
  * To update the previous cue to the current cue in the selected sequence, type:

```
Update Cue Previous
```
---|---  
  
  

  * To update the second previous cue to the current cue in the selected sequence type:

```
Update Cue Previous 2
```
---|---  
  
  

|  **Important:**  
---|---  
The examples that use **Previous** can use **Next** to **do the opposite**.  
  
  
  

  

  * To update the cue that is sitting one digit before the current cue in the selected sequence, type:

```
Update Cue - 1
```
---|---  
  
  

  * To update cue that is sitting 0.1 digits before the current cue in the selected sequence, type:

```
Update Cue - 0.1
```
---|---  
  
For more information on the key and its location see [Update key](https://help.malighting.com/grandMA3/2.5/HTML/key_update.html).
