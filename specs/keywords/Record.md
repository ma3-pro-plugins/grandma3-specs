## Official

To enter the Record keyword in the command line, use one of the options:

  * Press `MA` \+ `Store`
  * Type **Record**
  * Type the shortcut**Rec**

### Description

The Record keyword is used to record a timecode show using the command line. 

For information on how to assign executors see [Assign Objects to an Executor](https://help.malighting.com/grandMA3/2.5/HTML/executor_assign.html). 

### Syntax

**Record (On/Off) Timecode ["Timecode_Name" or Timecode_Number]**

### Example  
  

  * To start recording timecode 3 in the timecode pool, type:

```
Record Timecode 3
```
