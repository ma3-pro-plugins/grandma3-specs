## Official

To enter the RunningPreset keyword in the command line, use one of the options:

  * Type **RunningPreset**
  * Type the shortcut **Runningp**

### Description

The RunningPreset keyword addresses presets that are playing back.

|  **Important:**  
---|---  
The numbers of the running presets are not equal to the numbers in the preset pool.  
  
  
### Syntax

[Function] RunningPreset ["RunningPreset_Name" or RunningPreset_Number]

### Example  
  

  * To disable currently running presets, type:

```
Off RunningPreset
```
---|---  
  
  

  * To list all running presets, change destination first and type:

```
ChangeDestination RunningPreset
```
---|---  
  
  

  * Then type:

| User name@Temp/Cmdlines/Cmdline 1/RunningPlaybacks>Set RunningPlayback Property "SelectedPlaybackType" "Preset"  
---|---  
  
  

  * After that type:

|  User name@Temp/Cmdlines/Cmdline 1/RunningPlaybacks>List   
---|---
