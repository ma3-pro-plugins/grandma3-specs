## Official

To enter the Unpress keyword in the command line, use one of the options:

  * Type **Unpress**
  * Type the shortcut **Unpr**

### Description

The Unpress keyword is used to simulate the unpressed state of a key. 

It is possible to assign this state to macros.

For more information see [Macros](https://help.malighting.com/grandMA3/2.5/HTML/macros.html). 

For information on how to assign executors see [Assign Objects to an Executor](https://help.malighting.com/grandMA3/2.5/HTML/executor_assign.html). 

### Syntax

[Function] Unpress [Object] ["Object_Name" or Object_Number]

### Example  
  

  * To disable Flash on the executor 203, type:

```
Flash Unpress Executor 203
```
