## Official

To enter the Press keyword in the command line, type **Press**. 

### Description

The Press keyword is used to simulate the pressed state of a key. 

It is possible to assign this state to macros.

For more information see [Macros](https://help.malighting.com/grandMA3/2.5/HTML/macros.html). 

For information on how to assign executors see [Assign Objects to an Executor](https://help.malighting.com/grandMA3/2.5/HTML/executor_assign.html). 

### Syntax

[Function] Press [Object] ["Object_Name" or Object_Number]

### Example  
  

  * To execute Flash on the executor 203, type:

```
Flash Press Executor 203
```
---|---  
  
To unpress a key, see [Unpress Keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_unpress.html).
