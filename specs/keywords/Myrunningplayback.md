## Official

To enter the MyRunningPlayback keyword in the command line, use one of the options:

  * Type **My****RunningPlayback**
  * Type the shortcut **My****Runningpl**

### Description

The MyRunningPlayback keyword addresses playbacks that were started by my user profile and that are currently playing back. 

|  **Important:**  
---|---  
The numbers of the running playbacks are not equal to the numbers in the playback pool.  
  
  
### Syntax

[Function] MyRunningPlayback ["MyRunningPlayback_Name" or MyRunningPlayback_Number]

### Examples  
  

  * To disable all of your playbacks that are currently running, type:

```
Off MyRunningPlayback
```
---|---  
  
  * To list all of my running playbacks, change destination first and type:

```
ChangeDestination MyRunningPlayback
```
---|---  
  
  

  * Then type:

|  User name@Temp/Cmdlines/Cmdline 1/RunningPlaybacks>Set RunningPlayback Property "SelectedMine" "Yes"  
---|---  
  
  

  * Ater that type:

|  User name@Temp/Cmdlines/Cmdline 1/RunningPlaybacks>List  
---|---
