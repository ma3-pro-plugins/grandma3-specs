## Official

To enter the ClearSelection keyword in the command line, use one of these options:

  * Type **ClearSelection**
  * Type the shortcut**CS or Clears**

### Description

The ClearSelection keyword is a function keyword which is used to deselect the selected fixtures.

For information on the key see the [Clear Key](https://help.malighting.com/grandMA3/2.5/HTML/key_clear.html).

For more information on the additional functions of the Clear keyword see [Clear](https://help.malighting.com/grandMA3/2.5/HTML/keyword_clear.html), [ClearActive](https://help.malighting.com/grandMA3/2.5/HTML/keyword_clear_active.html), [ClearAll](https://help.malighting.com/grandMA3/2.5/HTML/keyword_clear_all.html).

### Syntax

ClearSelection

### Example  
  

  * To deselect selected fixtures, type:

```
ClearSelection
```
