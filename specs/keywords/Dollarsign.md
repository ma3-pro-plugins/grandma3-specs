## Official

To enter the $ (dollar sign) in the command line, type **$**. 

###  Description 

The $ (dollar sign) character is used to address variables using the command line.

For more information on how to set variables see [SetUserVariable keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_setuservariable.html) and the topic [Variables](https://help.malighting.com/grandMA3/2.5/HTML/macro_variables.html).

### Syntax 

[Function] $[Variable_Name]

###  Example  
  

  * To log into user, whose name is stored in the variable "JanePublic", type: 

```
LogIn $JanePublic
```
