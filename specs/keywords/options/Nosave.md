## Official

To enter the **/NoSave** option keyword in the command line, use one of the options:

  * Type **/NoSave**
  * Type the shortcut**/NS** or **/Nosa**

### Description

The /NoSave option keyword defines for the show file not to be saved when loading a show, or shuttig down, restarting, or rebooting the console or your onPC. 

|  **Important:**  
---|---  
The /NoSave option keyword only works in the conjunction with the [/NoConfirmation option keyword](https://help.malighting.com/grandMA3/2.5/HTML/ok_noconfirmation.html).  
  
  
### Syntax

**[Function] ([Object] ["Object_Name" or Object_Number]) /NoConfirmation /NoSave**

### General Keywords

General keywords that use the /NoSave option keyword:

  * [LoadShow keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_loadshow.html)
  * [Reboot keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_reboot.html)
  * [Restart keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_restart.html)
  * [ShutDown keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_shutdown.html)

### Example  
  

  * To shut down the grandMA3 console without saving the show file, type:

```
ShutDown /NoConfirmation /NoSave
```
