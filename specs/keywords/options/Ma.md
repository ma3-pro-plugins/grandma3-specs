## Official

To enter the **/MA** option keyword in the command line, use one of the options: 

  * Type **/MA**

###  Description 

The /MA option keyword is used to address a secondary function of an executor. 

###  Syntax 

Assign [Function] At Page ["Page_Name" or Page_Number].["Executor_Name" or Executor_Number] /MA

Assign [Function] At Executor ["Executor_Name" or Executor_Number] /MA

###  Example   
  

  * To assign Goto to `MA` \+ executor of page 1, executor 201, type: 

```
Assign Goto At Page 1.20 /MA
```
