## Official

To enter the **/File** option keyword in the command line, use one of the options:

  * Type **/File**
  * Type the shortcut**/Fi**

### Description

The /File option keyword is used to specify the file name of objects during import or export. 

### Syntax

[Function] [Object] ["Object_Name" or Object_Number] (If Drive [Drive_Number]) /File ["File_Name"]

### General Keywords

General keywords that use the /File option keyword:

  * [Export keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_export.html)
  * [Import keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_import.html)

### Example  
  

  * To export the preset file Endor, type:

```
Export Preset 2.5 /File "Endor"
```
