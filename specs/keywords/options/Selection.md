## Official

To enter the **/Selection** option keyword in the command line, use one of the options:

  * Type **/Selection**
  * Type the shortcut**/Selectio**

### Description

The /Selection option keyword defines if the current selection will be stored in a recipe. 

For more informtion on how recipes work see [Recipes](https://help.malighting.com/grandMA3/2.5/HTML/recipes.html). 

### Syntax

Store Preset ["FeatureGroup_Name" or FeatureGroup_Number].["Preset_Name" or Preset_Number].["Recipe_Name" or Recipe_Number] /Selection ["Option_Value"]

Store Sequence ["Sequence_Name" or Sequence_Number] Cue ["Cue_Name" or Cue_Number] Part ["Part_Name" or Part_Number].["Recipe_Name" or Recipe_Number] /Selection ["Option_Value"]

### General Keywords

General keywords that use the /Selection option keyword:

  * [Preset keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_preset.html)
  * [Sequence keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_sequence.html)
  * [Store keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_store.html)

### Example  
  

  * In order not to store the current selection into the recipe, type:

```
Store Preset 3.2.1 /Selection "No"
```
