## Official

To enter the **/Save** option keyword in the command line, use one of the options:

  * Type **/Save**
  * Type the shortcut**/Sa**

### Description

The /Save option keyword defines for the show file to be saved when loading a show, shuttig down, restarting, or rebooting the console or your onPC.

|  **Important:**  
---|---  
The /Save option keyword only works in the conjunction with the [/NoConfirmation option keyword](https://help.malighting.com/grandMA3/2.5/HTML/ok_noconfirmation.html).  
  
  
### Syntax

**[Function] ([Object] ["Object_Name" or Object_Number]) /NoConfirmation /Save**

### General Keywords

General keywords that use the /Save option keyword:

  * [LoadShow keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_loadshow.html)
  * [Reboot keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_reboot.html)
  * [Restart keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_restart.html)
  * [ShutDown keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_shutdown.html)

### Example  
  

  * To shut down the grandMA3 console and saving the current show file suppressing the confirmation pop-up, type:

```
ShutDown /NoConfirmation /Save
```
