## Official

To enter the **/MoveValues** option keyword in the command line, use one of the options:

  * Type **/MoveValues**
  * Type the shortcut**/MV** or **/Mo**

### Description

The /MoveValues option keyword is used to move values to part 0 when deleting cue parts. 

### Syntax

Delete Cue ["Cue_Name" or Cue_Number] Part ["Part_Name" or Part_Number] /MoveValues

### General Keywords

General keywords that use the /MoveValues option keyword:

  * [Cue keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_cue.html)
  * [Delete keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_delete.html)
  * [Part keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_part.html)

### Example  
  

  * To delete part 5 of cue 7, and move the values to part 0 of cue 7, type:

```
Delete Cue 7 Part 5 /MoveValues
```
