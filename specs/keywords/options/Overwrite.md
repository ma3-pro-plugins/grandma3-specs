## Official

To enter the **/Overwrite** option keyword in the command line, use one of the options:

  * Type **/Overwrite**
  * Type the shortcut **/O**

### Description

The /Overwrite option keyword is used to overwrite existing values.

### Syntax

[Function] [Object] ["Object_Name" or Object_Number] /Overwrite

### General Keywords

General keywords that use the /Overwrite option keyword:

  * [AutoStore keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_autostore.html)
  * [Cook keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_cook.html)
  * [Clone keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_clone.html)
  * [Cue keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_cue.html)
  * [Filter keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_filter.html)
  * [Group keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_group.html)
  * [MAtricks keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_matricks.html)
  * [Preset keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_preset.html)
  * [Sequence keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_sequence.html)
  * [Store keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_store.html)
  * [World keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_world.html)

### Examples

  * To overwrite the existing values of cue 5 in sequence 1, type:

| User name[Fixture]>Store Sequence 1 Cue 5 /Overwrite |
| --- |

  * To clone the programmer data of fixture 1 to fixture 2 and overwrite all the data of fixture 2 in the programmer, type:

| User name[Fixture]>Clone Fixture 1 At Fixture 2 /Overwrite |
| --- |
