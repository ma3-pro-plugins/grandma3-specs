# Option Keyword Specs

**84 option** keywords for Target ([`../../versions.md`](../../versions.md)). See also [`../_index.md`](../_index.md).
Shortcuts live in each Spec’s frontmatter — not listed here.

| Keyword | Description |
| --- | --- |
| [`/Active`](Active.md) | The /Active option keyword stores all active values of the programmer no matter the selection. |
| [`/ActiveForSelected`](Activeforselected.md) | The /ActiveForSelected option keyword stores all active attributes of the selected fixtures in the programmer. |
| [`/AddNewContent`](Addnewcontent.md) | The /AddNewContent option keyword updates existing values of attributes and adds new values in presets or cues. |
| [`/All`](All.md) | The /All option keyword stores the values of all attributes when using Data Source Output or DMX. |
| [`/AllForSelected`](Allforselected.md) | The /AllForSelected option keyword stores all attributes of the selected fixtures in the programmer. |
| [`/Ask`](Ask.md) | The /Ask option keyword is a default setting which is used to define the store option in an object that already has values. |
| [`/Async`](Async.md) | The /Async option keyword is used to asynchronously execute remote commands. |
| [`/Auto`](Auto.md) | The /Auto option keyword is used to store and update presets. |
| [`/AutoFit`](Autofit.md) | The /AutoFit option keyword is used to position any window in the next unoccupied area of a specified screen respecting the minimum requirements of the window. |
| [`/AutoStart`](Autostart.md) | The /AutoStart option keyword is used to define which sequences will start if you enter the preview mode. |
| [`/ChannelSet`](Channelset.md) | The /ChannelSet option keyword is used in conjuction with the AutoCreate keyword – whereby the AutoCreate command creates objects out of channel sets. |
| [`/CopyCueDestination`](Copycuedestination.md) | The /CopyCueDestination option keyword defines how the copied data is used in the destination cue when copying cues. |
| [`/CopyCueSource`](Copycuesource.md) | The /CopyCueSource option keyword defines how data is extracted in the source cue when copying cues. |
| [`/CreateReferenceObject`](Createrefernceobject.md) | The /CreateReferenceObject option keyword creates a referenced object when an object is imported. |
| [`/CreateSecondCue`](Createsecondcue.md) | The /CreateSecondCue option keyword stores a cue using the next whole number provided the sequence has only one cue. |
| [`/CueOnly`](CueOnly.md) | The /CueOnly option keyword blocks tracked values in the next cue or cue part to preserve the previous look on stage. |
| [`/Date`](Date.md) | The /Date option keyword changes the start date of an agenda event that is to be pasted from clipboard. |
| [`/Default`](Default.md) | The /Default option keyword is used when copying cues. |
| [`/DiscardChanges`](Discardchanges.md) | The /DiscardChanges option keyword is used to leave the Patch without storing the changes. |
| [`/DMX`](Dmx.md) | The /DMX option keyword is used to store incoming DMX data to cues or presets. |
| [`/DMXProtocols`](Dmxprotocols.md) | The /DMXProtocols option keyword is used to load the DMX protocol settings (Art-Net and sACN) of the show file. |
| [`/Embed`](Embed.md) | The /Embed option keyword is used to store presets that are active in the programmer into a preset. |
| [`/Enumerate`](Enumerate.md) | The /Enumerate option keyword is used to add a count to the name of a show file. |
| [`/File`](File.md) | The /File option keyword is used to specify the file name of objects during import or export. |
| [`/ForceGlobal`](Forceglobal.md) | The /ForceGlobal option keyword adds global data to a preset already containing selective data. |
| [`/ForceUniversal`](Forceuniversal.md) | The /ForceUniversal option keyword adds universal data to a preset and sets preset mode to universal. |
| [`/Gaps`](Gaps.md) | The /Gaps option keyword retains or suppresses empty spaces when importing or exporting a range of pool objects. |
| [`/GDTF`](Gdtf.md) | The /GDTF option keyword is used during export of a fixture type that uses the GDTF format. |
| [`/Global`](Global.md) | The /Global option keyword is used to store or update global data into presets regardless their mode. |
| [`/GridMergeMode`](Gridmergemode.md) | The /GridMergeMode option keyword is used when storing fixtures with their selection grid data into objects using the merge mode. |
| [`/HighPrecision`](Highprecision.md) | The /HighPrecision option keyword is used to increase the precision of metrics in fixture types during their export. |
| [`/Indirect`](Indirect.md) | The /Indirect option keyword is used to directly edit an assigned object. |
| [`/InputFilter`](Inputfilter.md) | The /InputFilter option keyword is used to enable or disable the filter of a feature group when storing or updating presets. |
| [`/KeepActivation`](Keepactivation.md) | The /KeepActivation option keyword is used to keep the programmer content still active after storing the preset. |
| [`/Limit`](Limit.md) | The /Limit option keyword defines how many entries will be displayed in the command line history. |
| [`/LocalSettings`](Localsettings.md) | The /LocalSettings option keyword is used to load the local settings of a show file. |
| [`/Look`](Look.md) | The /Look option keyword stores all dimmer values of all fixtures in the show. |
| [`/MA`](Ma.md) | The /MA option keyword is used to address a secondary function of an executor. |
| [`/MAtricks`](Matricks.md) | The /MAtricks option keyword is used to store the MAtricks settings in the preset whenever the MAtricks are active. |
| [`/Merge`](Merge.md) | The /Merge option keyword merges new values with existing values. |
| [`/MergeHighPriority`](Mergehightpriority.md) | The /MergeHighPriority option keyword adds all data that is in the source to destination. |
| [`/MergeLowPriority`](Mergelowpriority.md) | The /MergeLowPriority option keyword adds data that is in the source to the destination only where it does not contain data. |
| [`/MoveValues`](Movevalues.md) | The /MoveValues option keyword is used to move values to part 0 when deleting cue parts. |
| [`/MVR`](Mvr.md) | The /MVR option keyword is used to export the patch as MVR file instead of a grandMA3 XML file. |
| [`/NDI`](Ndi.md) | The /NDI option keyword stores screenshots of NDI streams directly as images. |
| [`/NoAutoClose`](Noautoclose.md) | The /NoAutoClose option keyword is used to suppress the countdown in pop-ups. |
| [`/NoConfirmation`](Noconfirmation.md) | The /NoConfirmation option keyword is used to suppress the confirmation pop-ups when storing objects or shutting down the station. |
| [`/NoDependencies`](Nodependencies.md) | The /NoDependencies option keyword is used to import or export data without the dependent objects. |
| [`/NoOops`](NoOops.md) | The /NoOops option keyword does not generate oops events when executing commands. |
| [`/NoRefresh`](Norefresh.md) | The /NoRefresh option keyword is used to suppress the refresh of libraries during import or export of objects. |
| [`/NoSave`](Nosave.md) | The /NoSave option keyword defines for the show file not to be saved when loading a show, or shuttig down, restarting, or rebooting the console or your onPC. |
| [`/NoShowData`](Noshowdata.md) | The /NoShowData option keyword is used to keep current show data when loading shows. |
| [`/NoSubfolders`](Nosubfolders.md) | The /NoSubfolders option keyword is used to exclude subfolders when importing library files or listing libraries. |
| [`/OddEven`](Oddeven.md) | The /OddEven option keyword is used to form two groups – odd and even – out of fixtures of a specific fixture type, class or layer, and range of fixtures and… |
| [`/OriginalContentOnly`](Originalcontentonly.md) | The /OriginalContentOnly option keyword updates already existing values of attributes in their original location in presets or cues. |
| [`/Output`](Output.md) | The /Output option keyword is used to store incoming output data to cues or presets. |
| [`/OutputStations`](Outputstations.md) | The /OutputStations option keyword is used to overwrite the current output stations with the output stations of the show file that will be loaded. |
| [`/Overwrite`](Overwrite.md) | The /Overwrite option keyword is used to overwrite existing values. |
| [`/PatchOffset`](Patchoffset.md) | When patching the /PatchOffset option keyword sets the offset of DMX addresses in fixtures. |
| [`/Path`](Path.md) | The /Path option keyword defines the folder path where an imported or exported file is saved. |
| [`/PhaserData`](Phaserdata.md) | The /PhaserData option keyword is used to define if attribute data will be stored in presets. |
| [`/Programmer`](Programmer.md) | The /Programmer option keyword is used to store active programmer data to cues or presets. |
| [`/Recipe`](Recipe.md) | The /Recipe option keyword can only be used together with the CleanUp keyword and only if the /Type option keyword is set to Recipe. |
| [`/Recursive`](Recursive.md) | The /Recursive option keyword is used to define which levels of objects you can lock or unlock. |
| [`/Release`](Release.md) | The /Release option keyword is used when copying cues. |
| [`/Remove`](Remove.md) | The /Remove option keyword is used to remove values that are stored in attributes and active programmer values. |
| [`/Save`](Save.md) | The /Save option keyword defines for the show file to be saved when loading a show, shuttig down, restarting, or rebooting the console or your onPC. |
| [`/Screen`](Screen.md) | The /Screen option keyword addresses screens when storing or calling views. |
| [`/ScreenOnly`](Screenonly.md) | The /ScreenOny option keyword defines which parts of the screen will be used when taking screenshots. |
| [`/Selection`](Selection.md) | The /Selection option keyword defines if the current selection will be stored in a recipe. |
| [`/Selective`](Selective.md) | The /Selective option keyword is used to store or update selective data into presets regardless their mode. |
| [`/Single`](Single.md) | The /Single option keyword is used when extracting presets or when autocreating single fixture groups. |
| [`/Sort`](Sort.md) | The /Sort option keyword defines how to sort results in the command line history. |
| [`/SubTab`](Subtab.md) | The /SubTab option keyword is used to switch between tabs within tab bars in the PSR menu. |
| [`/Tab`](Tab.md) | The /Tab option keyword is used to define which tab will open in the assign menu. |
| [`/TrackingShield`](Trackingshield.md) | The /TrackingShield option keyword is used to protect tracked attributes when storing values. |
| [`/TransferProgrammer`](Transferprogrammer.md) | The /TransferProgrammer option keyword is used to transfer the programmer into preview mode. |
| [`/TransferSelection`](Transferselection.md) | The /TransferSelection option keyword is used to transfer the selection of fixtures into preview mode. |
| [`/Type`](Type.md) | The /Type option keyword can have different values depending on the keyword it is combined with. |
| [`/Universal`](Universal.md) | The /Universal option keyword is used to store or update universal data into presets regardless their mode. |
| [`/Wait`](Wait.md) | In conjunction with the Store keyword /Wait option keyword defines the latency time in milli seconds after which your command will be executed. |
| [`/Wrap`](Wrap.md) | The /Wrap option keyword loops through all steps and selects the first step after reaching the last step. |
| [`/XResolution`](Xresolution.md) | The /XResolution option keyword defines the resolution of images on the x-axis during storing. |
| [`/YResolution`](Yresolution.md) | The /YResolution option keyword defines the resolution of images on the y-axis during storing. |
