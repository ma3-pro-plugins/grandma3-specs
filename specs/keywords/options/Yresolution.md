## Official

To enter the **/YResolution** option keyword in the command line, use one of the options: 

  * Type **/YResolution**
  * Type the shortcut**/Y**

###  Description 

The /YResolution option keyword defines the resolution of images on the y-axis during storing. 

Syntax

Store Image ["MediaPool_Name" or MediaPool_Number].["Image_Name" or Image_Number] /YResolution ["YResolution_Value"]

###  General Keywords 

General keywords that use the /YResolution option keyword: 

  * [Store keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_store.html)

###  Example   
  

  * To store a sceenshot of screen 2 with a resolution of 256 on the y-axis, type: 

```
Store Image 3.3 /Screen "2" /YResolution "256"
```
