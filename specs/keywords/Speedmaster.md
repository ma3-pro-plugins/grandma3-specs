## Official

To enter the SpeedMaster keyword in the command line, use one of the options:

  * Type **SpeedMaster**
  * Type the shortcut **Speedm**

### Description

The SpeedMaster is a layer keyword. It defines which speed master the phaser is to adapt its speed to in each attribute. 

|  **Hint:**  
---|---  
You can set speed masters using the speed readouts BPM, Hertz, or Seconds. For more informations see the [Master keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_master.html).  
  
  
### Syntax

**SpeedMaster**

(Attribute ["Attribute_Name" or Attribute_Number]) At SpeedMaster [SpeedMaster_Number]

### Examples  
  

  * To set the layer to speed master, type:

```
SpeedMaster
```
---|---  
  
  * To set attribute "Pan" to SpeedMaster 1, type:

```
Attribute "Pan" At SpeedMaster 1
```
