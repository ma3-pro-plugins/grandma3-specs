## Official

To enter the LoadShow keyword in the command line, use one of the options:

  * Type **LoadShow**
  * Type the shortcut **Lo**

### Description

The LoadShow keyword is a function keyword that loads a show from the folders: shows, demo shows, or backup**.**

For more information on the folder structure of shows, demo shows, and backups, see [Show File ](https://help.malighting.com/grandMA3/2.5/HTML/show_file_management.html#FolderStructure)[Handling](https://help.malighting.com/grandMA3/2.5/HTML/show_file_management.html#FolderStructure) and [Folder Structure](https://help.malighting.com/grandMA3/2.5/HTML/fm_folder_structure.html). 

### Syntax

LoadShow ["Show_Name"] (/Option)

### Option Keywords

The LoadShow keyword uses the following option keywords:

  * [/All](https://help.malighting.com/grandMA3/2.5/HTML/ok_all.html)
  * [/DMXProtocols](https://help.malighting.com/grandMA3/2.5/HTML/ok_dmxprotocols.html)
  * [/LocalSettings](https://help.malighting.com/grandMA3/2.5/HTML/ok_localsettings.html)
  * [/NoSave](https://help.malighting.com/grandMA3/2.5/HTML/ok_nosave.html)
  * [/NoShowData](https://help.malighting.com/grandMA3/2.5/HTML/ok_noshowdata.html)
  * [/OutputStations](https://help.malighting.com/grandMA3/2.5/HTML/ok_outputstations.html)
  * [/Path](https://help.malighting.com/grandMA3/2.5/HTML/ok_path.html)
  * [/Save](https://help.malighting.com/grandMA3/2.5/HTML/ok_save.html)
  * [/Type](https://help.malighting.com/grandMA3/2.5/HTML/ok_type.html)

### Examples  
  

  * To load the show file with the file name "MacBeth", type:

```
LoadShow "MacBeth"
```
---|---  
  
  * To create a new show file with the name "Henrietta", type:

```
LoadShow "Henrietta"
```
---|---  
  
|  **Important:**  
---|---  
To load the new show again, save the new show file after loading it. For more information see [SaveShow keyword](https://help.malighting.com/grandMA3/2.5/HTML/keyword_saveshow.html).
