## Official

To enter the ClearActive keyword in the command line, use one of the options:

  * Type **ClearActive**
  * Type the shortcut **Ca** or **Clearac**

### Description

​The ClearActive keyword is used to deactivate all values in the programmer. 

For information on the key see the [Clear Key](https://help.malighting.com/grandMA3/2.5/HTML/key_clear.html).

For more information on the additional functions of the Clear keyword see [Clear](https://help.malighting.com/grandMA3/2.5/HTML/keyword_clear.html), [ClearAll](https://help.malighting.com/grandMA3/2.5/HTML/keyword_clear_all.html), [ClearSelection](https://help.malighting.com/grandMA3/2.5/HTML/keyword_clear_selection.html). 

### Syntax

ClearActive

### Example  
  

  * To deactivate active values in the programmer, type:

```
ClearActive
```
