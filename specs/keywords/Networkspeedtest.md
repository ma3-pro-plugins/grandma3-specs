## Official

To enter the NetworkSpeedTest keyword in the command line, use one of the options:

  

  * Type **NetworkSpeedTest**
  * Type the shortcut **Net**

### Description

The NetworkSpeedTest keyword is used to excute a test of the network connection in devices defined in the command.

### Syntax

NetworkSpeedTest [DeviceType] ["Device_Name" or Device_Number]

### Examples

  * To execute a network speed test in all consoles that are available in the network, type:

```
NetworkSpeedTest Console Thru
```
---|---  
  
  

  * To test all devices in your session, type:

```
NetworkSpeedTest Session
```
---|---
